## Fractal Quarterly Macro Model Indicator

This repository includes a TradingView Pine Script indicator implementing the **Fractal Quarterly Macro Model with Time Doubling**. The script visualizes macro price behavior using a four-phase cycle (A/M/D/X) and plots time-doubling markers for potential reactions.

File: `FractalMacroModel.pine`

Basic features:
- Select cycle flow: `AMDX` or `XAMD`.
- Customize the base cycle length and root offset.
- Background coloring for each macro phase.
- Vertical lines for time-doubling intervals (1x, 2x, 4x, 8x, 16x).
- Optional labels and simple entry signals near phase transitions.
